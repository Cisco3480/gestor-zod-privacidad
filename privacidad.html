Política de privacidad — Gestor Personal Zod

Última actualización: 13 de octubre de 2026

Qué es

«Gestor Personal Zod» es una herramienta privada y de uso personal: la usa una sola persona, su dueño, para organizar su propio correo de Gmail. No es un servicio para el público, no tiene usuarios externos y no se ofrece a terceros.

Qué datos usa y para qué

  • Con permiso explícito del dueño de la cuenta, la herramienta lee sus correos recientes (remitente, asunto, fecha y contenido) para hacerle un resumen privado.
  • Puede crear borradores de respuesta en esa misma cuenta. Nunca envía correos: el dueño revisa y envía él mismo, si quiere.
  • No borra, archiva ni modifica correos.

Con quién se comparte

  • Los datos se usan solo para generar el resumen del propio dueño. No se venden, no se usan para publicidad y no se comparten con terceros.
  • Para redactar el resumen, el contenido de los correos se procesa con el modelo de IA Claude de Anthropic, a través de su API, únicamente para devolver ese resumen.
  • El acceso a Gmail se hace con la API oficial de Google. El permiso se guarda cifrado en un servidor privado del dueño y puede revocarse en cualquier momento.

Uso de datos de las API de Google

El uso y la transferencia de la información recibida de las API de Google se ajustan a la Política de datos de usuario de los servicios de API de Google, incluidos sus requisitos de uso limitado.

Conservación y revocación

No se guardan copias de los correos: el resumen se genera y se entrega al dueño. El dueño puede retirar el acceso en cualquier momento desde myaccount.google.com/permissions.

Contacto

Para cualquier consulta, usa el correo de soporte que aparece en la pantalla de autorización de Google de esta aplicación.

¿Esto envía correos?

No. Solo lee y crea borradores; enviar lo hace siempre el dueño a mano.

¿Quién lo usa?

Una sola persona, para su propia cuenta. No es un servicio público.

¿Cómo quito el acceso?

En myaccount.google.com/permissions, en «Gestor Personal Zod», pulsa «Quitar acceso».
